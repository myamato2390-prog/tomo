# tomo

コードに慣れるための練習用リポジトリ。

## 数当てゲーム (`guess_number.py`)

コンピュータが決めた 1〜100 の数を当てるゲームです。

### 実行方法

```bash
python3 guess_number.py
```

### 遊び方の例

```
=== 数当てゲーム ===
1〜100 の数を入力してください: 50
もっと小さいです。
1〜100 の数を入力してください: 25
もっと大きいです。
1〜100 の数を入力してください: 37
正解！ 3 回で当たりました。
```

### 慣れてきたら挑戦してみよう（改造アイデア）

1. 範囲を 1〜1000 に変えてみる
2. 10 回以内に当てられなかったら「ゲームオーバー」にする
3. 終わったあと「もう一回遊ぶ？ (y/n)」と聞いてくり返せるようにする
4. 一番少ない回数（ベスト記録）を表示する
